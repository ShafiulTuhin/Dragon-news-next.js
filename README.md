🌐 Dragon News (Next.js News Platform)

Live Demo: https://dragon-news-next-js.vercel.app

Dragon News is a modern, responsive front-end news web application built with Next.js. It provides users with real-time access to news articles across multiple categories, delivering a smooth and dynamic reading experience.

The platform integrates Better Auth authentication to ensure secure user registration and login functionality, allowing users to access personalized features safely.

With a clean UI and optimized performance, Dragon News offers fast navigation, categorized news browsing, and a fully responsive design that works seamlessly across all devices.

✨ Key Highlights
📰 Real-time news feed with categorized collections
🔐 Secure authentication using Better Auth
⚡ Built with Next.js for high performance and SEO optimization
📱 Fully responsive design for mobile, tablet, and desktop
🎯 Clean and user-friendly interface for better reading experience
🚀 Deployed on Vercel for fast and reliable hosting
